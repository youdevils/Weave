Import data

Add data to an existing object or relationship type from a CSV or Excel file. Imports create a proposal for review; they do not change the model directly.

Upload file

Select the file you want to import.

CSV (UTF-8), Excel (.xlsx) or legacy Excel (.xls), with a single table or worksheet. Up to {{ import_bootstrap.limits.max_rows }} data rows and {{ import_bootstrap.limits.max_file_mb }} MB.

Choose destination

Tell OnyxJar what kind of data the file contains and where it belongs.

Choose a type that already exists in this model. Importing adds data to it and never creates or changes types.

Map columns

Choose which model field each column should populate. Columns you leave unmapped are ignored.

  • To update records that already exist, map a column that identifies them: an OnyxJar ID, or one of the type’s own attributes (such as an application id from your source system) marked “Use to identify”.
  • Names are never used to match records.
  • A blank cell clears the corresponding value.

Preview changes

Review the changes this import would propose before creating it.

Create proposal

Create one proposal containing these changes. The imported file is retained as evidence, and nothing is committed until the proposal is submitted.
