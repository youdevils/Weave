Data Import

Populate this model from a CSV, Excel (.xlsx) or legacy Excel (.xls) file with a single table or worksheet. An import never changes the model directly: it creates one proposal that you review, and the usual validation decides what is allowed. It fills in the types you have already defined; it does not create or change them.

1 Upload

CSV must be UTF-8. Workbooks must have exactly one worksheet. Up to {{ import_bootstrap.limits.max_rows }} data rows and {{ import_bootstrap.limits.max_file_mb }} MB.

2 Target

Each import fills in one existing type.

3 Map columns

Choose the field each column feeds. Columns you leave alone are ignored. To update records that already exist, map a column that identifies them: an OnyxJar ID, or one of the type’s own attributes (such as an application id from your source system) marked “use to identify”. Names are never used to match records. A blank cell sets that value to empty.

4 Preview changes

5 Create proposal

Creates one working proposal containing these changes, each linked to your file as evidence, and opens it for review. Nothing is committed until you submit it.
