Publishing

Publish

Choose what to include, check the preview, then publish a read-only copy that works offline. A publication is a snapshot of the model's approved content at revision {{ model.revision }}; proposed changes are never included.

Publication settings

Theme colour
Colours the header of the published file.
Opening view

Select an object in the preview, then use it as what readers open on.

Please note: the published file includes each item's history and evidence, including the email address of whoever proposed each change. Anyone with the file can read it.

Publication scope

What goes into the publication. The starting point, types and filters below all apply together; nothing you leave out can appear in the file.

Starting point

Start the publication from a specific object. Only that object and everything connected to it within the selected number of steps will be included. Leave it empty to start from the whole model. The types and filters below still apply within this result.

Object filters

Limit which objects are published by an attribute value, for example only Stores whose Status is Active. Filters apply on top of the starting point and the types above, and only to objects.
